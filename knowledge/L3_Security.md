# L3 Security

## Overview
L3 (Layer 3) security operates at the network layer of the OSI model, controlling traffic based on IP addresses, subnets, and routing rules. It is the foundation of network segmentation.

## Notes
- Filters based on source/destination IP addresses and CIDR blocks
- Implemented via routing rules, ACLs, IPsec, VPNs
- Examples: subnet isolation, VPC peering rules, IP allowlists
- IPsec provides L3 encryption and authentication
- Foundation for network segmentation and zero-trust architectures
- Cannot distinguish between services on the same host

## 한국어

### 개요
L3 (Layer 3) 보안은 OSI 모델의 네트워크 계층에서 동작하며, IP 주소, 서브넷, 라우팅 규칙을 기반으로 트래픽을 제어합니다. 네트워크 세분화의 기반입니다.

### 노트
- 소스/대상 IP 주소와 CIDR 블록 기반 필터링
- 라우팅 규칙, ACL, IPsec, VPN으로 구현
- 예: 서브넷 격리, VPC 피어링 규칙, IP 허용 목록
- IPsec은 L3 암호화와 인증 제공
- 네트워크 세분화와 제로 트러스트 아키텍처의 기반
- 동일 호스트의 서비스 간 구분 불가
