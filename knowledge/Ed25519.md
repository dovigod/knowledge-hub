# Ed25519

## Overview
Ed25519 is a public-key signature scheme based on the Edwards-curve Digital Signature Algorithm (EdDSA) using the Curve25519 elliptic curve. It produces small, fast signatures with strong security properties and is the recommended default for new SSH keys.

## Notes
- **Key size**: 256-bit private key with a 32-byte public key — far smaller than equivalent-strength RSA keys (3072+ bits).
- **Performance**: significantly faster signing and verification than RSA at comparable security levels.
- **Determinism**: signatures are deterministic, removing the need for a strong per-signature random number and avoiding entire classes of nonce-reuse bugs.
- **SSH usage**: generated with `ssh-keygen -t ed25519`. Supported by OpenSSH 6.5+ (2014) and modern Git hosts.
- **Versus RSA/ECDSA**: preferred over RSA for new deployments and generally preferred over NIST P-curve ECDSA for transparency of design.

## 한국어

### 개요
Ed25519는 Curve25519 타원곡선을 기반으로 하는 EdDSA(Edwards-curve Digital Signature Algorithm) 서명 방식이다. 서명 크기가 작고 빠르며 보안성이 우수해 새 SSH 키의 기본 추천 알고리즘으로 자리 잡았다.

### 노트
- **키 크기**: 256비트 개인키와 32바이트 공개키로, 동등한 보안 수준의 RSA 키(3072비트 이상)보다 훨씬 작다.
- **성능**: 같은 보안 강도에서 RSA보다 서명/검증 속도가 매우 빠르다.
- **결정적 서명**: 서명이 결정적이라 매번 안전한 난수가 필요하지 않으며, 논스 재사용으로 인한 버그를 원천 차단한다.
- **SSH 사용**: `ssh-keygen -t ed25519`로 생성하며, OpenSSH 6.5(2014) 이상과 주요 Git 호스트에서 지원된다.
- **RSA/ECDSA와 비교**: 새 환경에서는 RSA보다 권장되며, 설계 투명성 측면에서 NIST P 곡선 기반 ECDSA보다 일반적으로 선호된다.
