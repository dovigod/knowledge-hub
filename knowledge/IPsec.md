# IPsec

## Overview
IPsec (Internet Protocol Security) is a suite of protocols that secures IP communications by authenticating and encrypting each IP packet in a communication session at the network layer (L3).

## Notes
- Operates at OSI Layer 3 (network layer)
- Two main protocols: AH (Authentication Header) and ESP (Encapsulating Security Payload)
- Two modes: Transport mode (host-to-host) and Tunnel mode (gateway-to-gateway)
- Foundation for many site-to-site VPN implementations
- Uses IKE (Internet Key Exchange) for key management
- Provides confidentiality, integrity, authentication, and anti-replay protection

## 한국어

### 개요
IPsec (Internet Protocol Security)은 네트워크 계층(L3)에서 통신 세션의 각 IP 패킷을 인증하고 암호화하여 IP 통신을 보호하는 프로토콜 모음입니다.

### 노트
- OSI 3계층(네트워크 계층)에서 동작
- 두 가지 주요 프로토콜: AH (Authentication Header)와 ESP (Encapsulating Security Payload)
- 두 가지 모드: 전송 모드(호스트 간)와 터널 모드(게이트웨이 간)
- 많은 사이트 간 VPN 구현의 기반
- 키 관리를 위해 IKE (Internet Key Exchange) 사용
- 기밀성, 무결성, 인증, 재전송 방지 제공
