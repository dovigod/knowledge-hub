## TL;DR

이 대화에서는 SSH 프로토콜과 Cilium 네트워킹 보안 개념을 다뤘다. 특히 Kubernetes에서 Cilium이 어떻게 L3, L4, L7 계층의 네트워크 정책을 적용하는지 설명했다.

## Key takeaways

- SSH는 안전하게 원격 서버에 접속하기 위한 프로토콜이다.
- Cilium은 Kubernetes의 네트워크 엔진(CNI)이다.
- L3 보안은 IP 주소나 네트워크 대역을 기준으로 허용하거나 차단한다.
- L4 보안은 TCP/UDP 포트 기준으로 통신을 제어한다.
- L7 보안은 HTTP 경로나 메서드 같은 애플리케이션 데이터를 보고 제어한다.
- Cilium은 eBPF(리눅스 커널 안에서 동작하는 기술)를 사용해 빠르게 패킷을 처리한다.
