# Assistant

QPS(Query Per Second)는 1초 동안 시스템이 처리한 요청 수를 의미한다. 보통 처리량(throughput)을 나타내는 지표로 사용되며, HTTP 요청, RPC 호출, DB 쿼리 등에 적용된다. QPS가 높을수록 시스템 부하가 크며, latency 및 error rate와 함께 봐야 한다.
